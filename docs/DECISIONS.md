# Архитектурные решения

## ADR-0001 — Manual import only

Статус: accepted. MVP принимает только архив, который пользователь загрузил сам. Это ограничивает охват, но резко снижает риск доступа к чужим данным и несанкционированной отправки.

## ADR-0002 — Draft, not send

Статус: accepted. Генерация заканчивается редактируемым черновиком. Отправка всегда вручную во внешнем приложении.

## ADR-0003 — TypeScript monolith first

Статус: accepted. Next.js + доменные пакеты + worker в одном репозитории. Разделение на сервисы отложено до измеренной необходимости.

## ADR-0004 — Provider adapter

Статус: accepted. AI-провайдер заменяем через интерфейс; модель и prompt version записываются в результат.

## ADR-0005 — Tenant-aware core

Статус: accepted. Workspace и ownership присутствуют с начала, но клубные роли и биллинг не входят в MVP.
