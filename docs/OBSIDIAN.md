# Obsidian: только решения и ссылки

Obsidian не должен становиться второй копией репозитория. В нём хранить:

- краткие ADR: решение, дата, статус, почему, последствия;
- ссылки на конкретные файлы/PR/release;
- вопросы, которые требуют решения пользователя;
- ссылки на официальные документы и исследования.

Не хранить исходники, длинные логи, повтор README или копии схем. Канонический текст живёт в Git; Obsidian содержит индекс и контекст. Шаблон заметки:

```md
# ADR-0001: Название
Статус: proposed | accepted | superseded
Дата: YYYY-MM-DD

Решение: ...
Почему: ...
Последствия: ...
Ссылки: [repo](...), [PR](...)
```
