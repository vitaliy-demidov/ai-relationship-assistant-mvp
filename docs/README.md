# AI-помощник для знакомств

Продуктовый blueprint для самостоятельного продукта: личный MVP сейчас и универсальное ядро для будущего white-label под бизнес-клубы и сообщества.

## Что зафиксировано

- MVP работает только с архивом диалогов, который пользователь импортировал сам и имеет право обрабатывать.
- Нет автоматической отправки сообщений, доступа к Telegram/Instagram и чтения чужих аккаунтов.
- Основной результат: список диалогов, карточка контакта, объяснимая рекомендация и редактируемый черновик сообщения.
- Архитектура сразу учитывает tenant/workspace, чтобы позже обслуживать несколько клубов, но MVP не перегружается клубными функциями.
- До реализации нет внешних подключений и секретов.
